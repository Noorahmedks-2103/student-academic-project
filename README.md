# Academic Learning Management Portal

## Overview

Academic Learning Management Portal is a Django-based web application that helps students access and manage academic resources through a centralized platform. It provides secure authentication and an intuitive interface for organizing learning materials and student activities.

---

## Features

- Secure user authentication
- Student profile management
- Study notes management
- Homework and To-Do management
- Dictionary and learning resources
- Responsive and user-friendly interface

---

## Tech Stack

- Python
- Django
- HTML
- CSS
- JavaScript
- SQL

## Installation

```bash
git clone https://github.com/ravi-928/academic-learning-management-portal.git

cd academic-learning-management-portal

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
